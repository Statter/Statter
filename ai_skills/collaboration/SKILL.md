# Коллаборация и командная работа

## Когда использовать
Каждый раз, когда ты необходимо провести анализ или внести изменения, перед тем как предлагать изменения

## Синонимы
Перечень синонимов для данного навыка:
- работа в совместном режиме
- изменения параллельно другим участникам
- проверка себя
- часть алгоритма выполнения задачи

## Критерий применимости
Если для выполнения задания требуется провести анализ текущего состояния проекта или отдельной его части, предложить варианты решения или изменить файлы (в том числе, если  выполненное задание в результате поменяет содержимое непосредственно глав книги, введения или дополнительной информации о проекте, то нужно выполнить алгоритм действий, указанный ниже
Если же выполнение задачи не затрагивало указанные выше аспекты, то алгоритм действий ниже применять не нужно

## Алгоритм действий
1. Когда начинается любая новая задача, связанная с анализом по данному проекту, то перед выполнением нужно актуализировать свое понимание текущего состояния проекта на случай, если другие участники в параллельном режиме внесли свои исправления
2. Актуализируется только состояние файлов, которые непосредственно затронуты заданием
3. Правки, внесенные в параллельном режиме, не удаляются из рабочей версии
4. Перед началом задачи ты отчитываешься о том, были ли внесены правки из вне нашего разговора 
5. Анализ задачи идет с учетом найденных сторонних правок, если такие присутствуют
6. Проверь себя, убедись, что предложение или внесенные изменения учитывают их, что все внесено корректно, и отчитайся по задаче
